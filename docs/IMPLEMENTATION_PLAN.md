# Tanglaw-Buhay implementation plan

Work on one approved task and deliverable at a time. Keep milestone status current using the definitions in [AGENTS.md](../AGENTS.md); only **Completed** requires verified acceptance criteria. Report results and stop for review before starting another task. This plan describes milestones, not authorization to implement all of them.

Phase 6B is a **single-municipality Pozorrubio pilot** supporting the **finalized 2022-compatible CBMS format**. The authorized working batch is historical 2022 data. The system is not intended to be limited permanently to that batch: future datasets are assumed to follow the same finalized structure, subject to validation before activation, historical-batch preservation, batch-specific assessments and role-based permissions. Cross-period household progression requires reliable identity matching and remains a future requirement, not implemented behavior. System Admin manages dataset imports and staff accounts; staff cannot access import functions. Automatic ETL validates files and preserves source responses. A failed import must leave the active dataset intact. Imported source records are read-only; authorized staff manage subsidy reviews separately. Existing MPI and subsidy calculations remain unchanged.
