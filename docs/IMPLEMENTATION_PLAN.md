# Tanglaw-Buhay implementation plan

This is the current development roadmap, not authorization to begin every listed task. Work on one approved deliverable at a time and stop for review. **Not Started** means work has not begun; **In Progress** means at least one scoped task has begun; **Blocked** means an unresolved issue prevents progress; **Completed** means acceptance criteria were verified. Follow [AGENTS.md](../AGENTS.md) for permanent safeguards, [UI_SPEC.md](UI_SPEC.md) for current staff UI direction, and [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) for system context. Historical task descriptions and old layouts remain in Git and do not override current requirements.

Keep milestone status current after each scoped task. Mark a task or phase Completed only when its own acceptance criteria have passed; do not infer completion of a whole phase from a completed foundation task.
