1. 1 Start here

    Upload and check the files

    Select the survey year and four required CSV files. Use Check files only to review them without saving.

    When the files pass, confirm their source and choose Check and store bundle.

    Go to the upload form {{ '↓' if current_import_step == 1 else '→' }}
  2. 2 After storing

    Prepare the assessments

    Open the stored batches page. Find the new inactive batch and choose Run and verify assessments.

    Continue only after the batch has a completed, designated run.

    Open stored batches {{ '↓' if current_import_step == 2 else '→' }}
  3. 3 Final step

    Activate the prepared dataset

    Open the active dataset page. Finish or cancel reviews still In Review, then confirm the prepared batch staff should use.

    The previous batch and its history remain stored.

    Open active dataset {{ '↓' if current_import_step == 3 else '→' }}
